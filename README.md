Shopora — E-Commerce Web Platform,
A full-stack e-commerce web application built entirely in Python using Flask and SQLite.

Features,
Buyer, Seller, and Admin roles with role-based access control,
Product listings with images, pricing, and categories,
Shopping cart and checkout/payment flow,
Star ratings and reviews on products,
Seller dashboard for managing products and viewing orders,
Admin dashboard with full visibility into all users and orders,
Seller business verification (GSTN, shop address),

Tech Stack,
Python, Flask, SQLite, Jinja2, Werkzeug (password hashing)

How to Run,
1. Install dependencies: pip install -r requirements.txt,
2. Run the app: python app.py,
3. Open http://127.0.0.1:5000 in your browser
